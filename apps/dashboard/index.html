How it works

1 · SDK in your appsReact Native, Expo and web. Wraps fetch; a Proxy records which response fields your code reads. Paths only: never values, URLs with ids, or headers.
2 · CollectorOne small Node service with SQLite. Aggregates reads per app version and counts active installs per version.
3 · CI checkbreakwater check diffs your OpenAPI spec, joins it with real reads, and fails the PR above your threshold.
Open source, MIT. “Not read” is strong evidence, not proof: a screen nobody opened in the window looks unused.
